## What's new

- **Xbox button tip:** with Xbox 360 emulation, the Emulation page shows which button each Xbox letter is
  (A = Cross, B = Circle, X = Square, Y = Triangle), since games then show Xbox buttons.
- **PC control page:** the Mapping page is now called PC control. Its settings are greyed out while PC control is off.
- New icons for the Controller and Settings pages.

## Fixes

- The controller on the Home page no longer jumps when the controller disconnects.
